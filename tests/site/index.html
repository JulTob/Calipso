The little test site

This site is small on purpose. It has a few pages that point to each other, so that a robot can walk from one to the next.

Start with the page about the sea, then read the page about the mountain. There is also a page in a folder.

Some links do not lead to pages: a file of notes, a drawing, a short film, a song and a thing with no name.

And some links must not be followed: a private page, another site, a letter and this same page.
